Why Digital Signatures?

Three important security properties.

👤

Authenticity

Helps verify that the message was signed using the expected private key.

🛡️

Integrity

If the message is changed after signing, verification fails.

🔏

Non-Repudiation

A properly implemented digital-signature system can provide evidence of who signed data.

📚 About This Demo

This demonstration uses the browser's built-in Web Crypto API. RSA-PSS is used to create and verify the digital signature, while SHA-256 is used as the hash algorithm.

The private key is used for signing, while the public key is used for verification.

Important: This is an educational demonstration and should not be treated as a complete production digital-signature system.
